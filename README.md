## Reading the project overviews

The **My contribution** sections describe responsibilities recorded in my activities and project background. The workflow and engineering sections explain behavior visible in the available source. Those sections may describe supporting components of a larger application; they do not claim that I independently authored the entire system.

The diagrams show how the main components interact, with accompanying explanations of application requests, persistence, media traffic, or network management as appropriate. Features found in a source snapshot are not presented as proof that every feature is currently deployed.

## Architecture notes

Software technology summaries reflect the reviewed project code; deployed versions may differ. The faculty network diagram is a conceptual view of the work described, rather than an exact physical topology. Where measurements or independent validation are unavailable, the descriptions avoid performance, availability, or clinical-validation claims.

This repository contains public descriptions and diagrams. Production source, credentials, user records, internal addresses, and deployment configurations are excluded.
